SHOCKRIDE GARAGE — WEBSITE TOKO ONLINE

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka folder shockride_store.
3. Klik dua kali index.html atau buka melalui browser.

Fitur:
- Tampilan tema gelap premium.
- Responsif untuk HP, tablet, dan laptop.
- Daftar 8 produk dengan foto.
- Harga produk ditampilkan Rp64.500 per unit.
- Keranjang belanja dengan tombol tambah/kurang jumlah.
- Total belanja dihitung otomatis.
- Tombol checkout membuka WhatsApp setelah produk dimasukkan ke keranjang.
- Nomor WhatsApp toko: 085865928665.

Catatan:
Harga Rp64.500 diterapkan untuk semua produk sebagai harga awal. Silakan ubah nilai `price:64500` pada daftar `products` di index.html jika harga tiap produk berbeda.
Ongkir dan ketersediaan stok tetap dikonfirmasi melalui WhatsApp.
